# 🐍 Natixis Python Level 2

## 📚 Course Overview

This intermediate course is designed for students who already have a working knowledge of Python and want to write code that is reusable rather than one-off. Students will learn to package logic into functions, express transformations concisely with comprehensions and `lambda`, use Python's built-in functional tools, and turn data into clear charts with Matplotlib and Seaborn. Every class is taught from a Google Colab notebook, so there is nothing to install.

> 📅 **Materials are published as the course progresses.** Each class appears here on the day it is taught, and its solutions afterwards.

## 🎯 Learning Objectives

By the end of this course, students will be able to:
- Define and use functions with parameters, return values, default and keyword arguments.
- Write a docstring that explains what a function is for.
- Explain the difference between a local and a global variable.
- Apply list, dictionary and set comprehensions to write concise, readable code.
- Create and use `lambda` functions for short inline operations.
- Use Python's built-in functions such as `map`, `filter`, `zip`, `any`, `all` and `sorted`.
- Sort data by any field using `sorted()` with a `key`.
- Build and customize charts with Matplotlib, and produce them faster with Seaborn.
- Combine several charts into one figure and export it.
- Structure a piece of analysis as a set of reusable functions rather than a single script.

## ✅ Prerequisites

Level 1 of this programme, or equivalent experience. Before taking this course, students should be familiar with:

- Python syntax, variables and the core data types
- Casting, and f-strings for formatted output
- Operators and expressions
- Control flow: `if` / `elif` / `else`, `for` and `while` loops, `break` and `continue`
- Core data structures: lists, tuples, sets and dictionaries
- Built-in functions such as `len`, `sum`, `min`, `max`, `sorted` and `enumerate`
- Basic usage of Pandas:
  - Reading a CSV and inspecting a DataFrame
  - Filtering rows and selecting columns
  - Handling missing values and duplicates
  - Creating columns and summarising with `groupby`

Level 2 is a prerequisite for Level 3.
